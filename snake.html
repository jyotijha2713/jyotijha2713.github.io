How a game works 🔁

Every game, from Snake to the biggest titles, runs the same loop over and over:

  1. Listen. Did the player press a key or swipe?
  2. Update. Move the snake one cell. Did it eat? Did it crash?
  3. Draw. Paint the new state on the screen.

Then wait a moment and go again. Here the wait is about a seventh of a second, and it gets shorter each time you eat. That's all the "speeding up" is.

Peek inside 🔧

Open snake.html in a text editor and find these lines near the top of the script:

var COLS = 20, ROWS = 20;
var START_MS = 140, MIN_MS = 65, SPEEDUP = 3;

Try a bigger board, or a faster start with START_MS = 90. Re-upload the file to GitHub and your version goes live. That's another commit, and now you're editing a project you can play.
